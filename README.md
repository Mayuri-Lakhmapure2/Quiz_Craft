QUIZ CRAFT — Interactive Quiz Platform

Quiz Craft is an interactive web-based quiz application designed to help users practice aptitude, reasoning, and company-specific MCQs. It features a clean UI, timer-based quizzes, clickable options, and a performance dashboard with visual analytics.

📌 Features

Clean and minimal UI

Custom styled radio buttons

Timer functionality

Prevents submission until all questions are answered

Dynamic result analysis

Donut chart to show performance

Responsive layout for all devices

Smooth button animations

Lightweight design theme
