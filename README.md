# 🎯 QUIZ CRAFT  
*A full-stack Quiz Application built with Node.js, Express, MongoDB, and EJS.*

---

## 🚀 Project Overview  
Quiz Craft is a complete aptitude quiz platform where users can attempt quizzes, view their scores, and analyze their performance through beautiful UI components such as charts and summary sections.

This project is designed to help students prepare for aptitude exams and company-specific tests.

---

## 🛠️ Tech Stack  

### **Frontend**
- EJS (Templating Engine)
- HTML5  
- CSS3  
- JavaScript  

### **Backend**
- Node.js  
- Express.js  

### **Database**
- MongoDB  
- Mongoose
